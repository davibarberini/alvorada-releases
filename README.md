# Alvorada — Terras da Aurora

Distribuição oficial do launcher para Windows 10/11 (64 bits).

[Baixar a versão mais recente](https://github.com/davibarberini/alvorada-releases/releases/latest)

Instale o arquivo `Alvorada-Setup-…-x64.exe`. Ao abrir, o launcher consulta novas versões, mostra as notas da atualização e conecta ao mundo online. A partir do launcher 0.1.7, patches do jogo são aplicados sem reiniciar o launcher. Se o jogo estiver aberto, o patch aguarda você fechar a janela do jogo. Atualizações do próprio launcher ainda usam o instalador e reiniciam o aplicativo. Nenhuma atualização encerra uma partida em andamento.

Releases `game-v…` são pacotes automáticos de conteúdo, não instaladores. Para instalar em outro PC, use sempre o link da versão mais recente acima.

Esta prévia não possui assinatura digital. O Windows pode avisar que o editor é desconhecido ou bloquear sua execução conforme a configuração de proteção do computador.

Este repositório contém apenas distribuição e notas de versão. O código-fonte do jogo permanece privado. O histórico completo está em **Releases**.
